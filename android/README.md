# Quick Call - Android App

Cold-calling list manager. Import numbers from camera, images, PDF, Excel, Word, etc.
Each contact appears in a large readable card with Call and WhatsApp buttons.

## Build
Open this `android/` folder in Android Studio (Hedgehog or newer) and run on a device/emulator.
Requires JDK 17.

## Features
- Import via camera (ML Kit OCR), image files, PDF (text extraction limited), Excel/CSV, Word (.docx), text
- Large, easy-to-read contact cards
- One-tap Call (dialer) and WhatsApp chat
- Search, manual add, delete, called status
