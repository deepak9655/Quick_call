# Quick Call

Employee cold-calling list manager.

## Web mockup / prototype
`mockup/` - React + Vite web app (PWA) demonstrating the final UI.
Run: `cd mockup && npm install && npm run dev`

## Android app
`android/` - Native Android project (Kotlin + Jetpack Compose).
Open in Android Studio and build. See `android/README.md`.

## Features
- Import numbers by camera (OCR), images, PDF, Excel/CSV, Word (.docx), text, or any file
- Large, easy-to-read contact cards
- One-tap Call and WhatsApp chat
- Search, manual add, delete, called status
